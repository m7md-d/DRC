# DRC interface

DRC uses a compact desktop layout for inspecting disks, creating images and reading files. Navigation, actions and results stay visually distinct.

- Use familiar macOS utility controls, aligned fields and resizable panes. Adapt the shared workspace to Linux conventions where needed.
- Use neutral surfaces with clear selection and state colors. Pair color with text or an icon.
- Use system typography for navigation and descriptions; monospace for commands, paths and exact values.
- Keep common tasks short and readable. Put detailed parameters and original output within reach of the related action.
- Easy guides the task; Professional exposes detailed controls. Switching modes preserves the page, inputs and selections.
- Label actions and reported results directly. Retain source names, exact readings, error codes and missing values without inventing a diagnosis.
- Reflow content for narrow windows. Support keyboard navigation, focus, contextual help and reduced motion.
