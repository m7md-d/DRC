DRC 0.4.0 adds an Easy workspace with observed disk statistics and clear inspection, imaging and image-exploration actions. Professional mode, complete fields and raw command output remain available. The offline command reference covers macOS and Debian-family Linux with searchable flags, effect labels and copy-only examples.

Linux discovery preserves lsblk, udev and sysfs output. Host evidence can collect PCIe/NVMe-controller attributes and kernel messages even when no block device appears. Imaging admits resolved secondary non-system SATA/NVMe disks, excludes mounted/system/swap sources and holds an exclusive read-only descriptor. When ordinary access is denied, the app can request a read-only descriptor through the system UDisks2 authorization service while staying unprivileged. Acquisition also offers explicit forward/reverse direction.

Debian 12 packages for amd64 and arm64 include GNU ddrescue 1.30 and private image-reader libraries. The build checks installation in a clean Debian runtime. Generated-source tests exercise short reads, disappearance errors, delayed stop and exact same-image/map resume; a separate generated loop-device test checks Linux's exclusive/read-only behavior. Scoped JSON results accompany the packages. These checks do not establish physical-SSD recovery or validate the desktop authorization flow.

Read LINUX-INSTALL.md, choose the matching architecture and verify SHA256SUMS before installation. Run the app as an ordinary desktop user. Rebinding a changed device identifier and adopting newer crash artifacts remain unavailable; a device exposing no readable logical sectors still requires capabilities outside software imaging.
