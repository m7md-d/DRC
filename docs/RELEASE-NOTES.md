DRC 0.4.2 improves the Easy workspace with a visual disk overview, reported partition proportions, compact readings and clear inspection, imaging and file-exploration actions. The layout adapts to wide and portrait native windows. Hover and keyboard-focus hints explain controls and readings. Capacities use readable decimal units; exact byte values remain available on hover/focus and in original output.

Port map adds a visual bus/hub/enclosure hierarchy to both workspaces. macOS collects System Profiler USB/Thunderbolt/NVMe reports and separate IORegistry USB and host-port trees. Linux retains canonical sysfs parents and paths. Each selected node exposes its original properties, reported power budgets and explicitly reported storage identifiers. These observations do not measure current or voltage reaching an enclosed SSD, prove controller response or diagnose a fault. Host-port counters and the distribution of driver-reported state durations are also visible; the driver's observation period is not inferred. Original tool streams are retained.

This release also includes the 0.4.0 offline macOS/Debian-family command guide and Linux acquisition backend. Debian 12 packages for amd64 and arm64 bundle GNU ddrescue 1.30 and private image-reader libraries. CI checks clean installation, generated-source failures/resume and Linux kernel exclusive/read-only claims on generated loop images. Scoped JSON evidence accompanies the packages. Physical SSD recovery, real desktop authorization, reconnects and blocked kernel reads remain separate validation work.

Read LINUX-INSTALL.md, select your architecture and verify SHA256SUMS. Run DRC as your ordinary desktop user. The application opens its own window and does not require a browser or development server.

The session store now explicitly releases its instance lock after closing the database. A concurrently spawned helper's briefly inherited descriptor can no longer prevent an immediate reopen. A regression test keeps such a descriptor alive across reopening and verifies that a second live store remains excluded. Version 0.4.1 did not pass the release gate; 0.4.2 includes this correction.
